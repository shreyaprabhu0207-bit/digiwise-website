DIGIWISE – AI Awareness and Healthy Social Media Habits for School Students

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the DIGIWISE folder.
3. Double-click index.html to open the website in a modern browser.
4. Use the navigation bar to visit the eight connected pages.

PAGES
Home, About, AI Basics, Healthy Social Media, Digital Footprint, Fact Check, Digital Wellbeing, Resources & Quiz.

TECHNOLOGIES
HTML5, CSS3 and vanilla JavaScript. No backend, database, account system or external API is used. Quiz feedback runs in the browser. The privacy checklist uses local browser storage on the same device.

NOTES
The website is an educational prototype, not a hosted public service. Resource links open external organisations. No personal data is collected or sent by the prototype.
